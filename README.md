# AI-Powered Meeting Assistant

An AI-powered platform designed to make online meetings more organized, productive, and easier to revisit. The system provides the foundation for managing meetings, real-time communication, and AI-powered processing of meeting data.

### Key Features

* **Meeting Management** — organize and manage meetings within separate organizations.
* **Real-Time Communication** — support real-time meeting experiences and instant notifications.
* **AI Processing** — provide a flexible foundation for AI-powered features such as meeting summarization, task extraction, and intelligent processing.
* **Semantic Search & RAG** — use embeddings and vector storage to enable retrieval and question-answering over meeting content.
* **Background Processing** — handle time-consuming AI and meeting-related operations asynchronously with reliable retry and failure handling.
* **Multi-Tenant Organizations** — securely isolate data between different organizations.

### Built With

**C# / .NET 10 · ASP.NET Core · PostgreSQL + pgvector · Hangfire · LiveKit · Docker**

The project follows a **feature-based modular monolith architecture**, with a strong focus on scalability, reliability, security, and extensibility.
